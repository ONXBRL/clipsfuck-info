clipsfuck · AI CLIPPER

Política de privacidad

Actualizada el 11 de noviembre de 2026.

Aplicación y contacto

clipsfuck · AI CLIPPER es una herramienta de uso personal que funciona en el PC del propietario. Contacto para privacidad: diositogt009@gmail.com.

Datos utilizados

La biblioteca local contiene los vídeos importados, clips, transcripciones, subtítulos, títulos y metadatos de los trabajos. Al vincular cuentas se guardan tokens OAuth e identificadores de los canales, páginas o cuentas autorizadas. La aplicación no necesita tus contraseñas de Google o Meta.

Datos de Google y permisos

Los permisos de YouTube permiten subir los clips aprobados y consultar información del canal y de sus publicaciones. Si conectas Google Drive por separado, se utiliza para las copias autorizadas y para mostrar el espacio de almacenamiento disponible. Los datos se usan únicamente para estas funciones solicitadas, no para publicidad ni para venderlos.

El uso y la transferencia de información recibida de las APIs de Google respetan la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado. Los datos de cuenta obtenidos de estas APIs no se utilizan para entrenar modelos de IA.

Servicios externos

Las publicaciones y las copias de Drive se transmiten al proveedor elegido. El análisis puede realizarse con modelos locales o con proveedores de IA configurados por el propietario, como OpenCode u OpenAI. Si se habilita el análisis externo, se envían los fragmentos de texto, audio o imágenes necesarios para esa función. No se envían tokens OAuth a los modelos.

Almacenamiento y seguridad

Los medios y la base de datos se conservan en el PC; las copias opcionales de Drive quedan en la cuenta conectada. La protección del disco depende de la configuración de Windows: la aplicación no cifra automáticamente la base de datos local. Las comunicaciones con los servicios externos utilizan HTTPS. La interfaz y la API locales se usan en el equipo del propietario.

Conservación, revocación y eliminación

Los archivos se conservan hasta que el propietario los elimina. La papelera de la biblioteca permite recuperar archivos durante su plazo configurado. Desconectar una cuenta elimina su vínculo local; también puedes revocar el acceso desde tu cuenta de Google o desde Meta. Esto no borra los vídeos que ya se hayan publicado ni las copias en Drive, que se gestionan en esas plataformas.

Para solicitar ayuda o eliminación de datos bajo el control del propietario, escribe al contacto anterior. Consulta las instrucciones de eliminación.
